WETLAND PLANT LOOKUP — GITHUB PAGES

Upload the contents of this folder to the ROOT of your GitHub repository (not the folder itself). Keep the data folder and its two JSON files. GitHub Pages must be set to Deploy from branch: main, folder: /(root).

Sources:
- data/usace.json: user-provided Army Corps of Engineers Plants spreadsheet (4,233 entries).
- data/sfwmd.json: FDEP Delineation Manual Appendix B, The Vegetative Index, printed pages 175–191 (781 OCR-transcribed entries).

Important: The PDF table was scanned and transcribed with OCR. The site preserves the transcribed source text and status, but OCR may contain errors. Confirm a critical species/status against the original manual. Do not treat the two source lists as interchangeable.

The app includes a service worker for offline use after the first successful load. On a phone, open the GitHub Pages URL and use Add to Home Screen / Install App.
